# 记忆写入决策树

本仓库文件。有实质性改动后、收尾时、**主动压缩或自动压缩前**逐条过；咨询 / 闲聊跳过。
可复用结论确认后**当时写**，不要攒到收尾。改过项目文件却未过本树时，Stop hook 每会话最多催一次（正文见 `memory-stop-nudge.md`）；hook 不自动改记忆文件。

写法、分类、删除门槛以 `.agents/ai-memory.md` 为准；本文件只做「写不写」分流。

**前置门：** 本次会话是否对项目产生了实质性改动？否 → 结束。

**默认不写。** 修了问题 ≠ 要记；做了选择 ≠ 要记；验证通过 ≠ 要写证据链。压缩不是额外写入理由。禁止把压缩摘要、排查过程、方案对比、验证步骤写入记忆文件。切断与恢复见 `.agents/context-compression-guidelines.md`。

## 写入目标

- 下回要接着干的未完成任务 → `TASK_MEMORY.md`（`.agents/task-memory.md`）
- 可复用短结论 → `AI_MEMORY.md`（`.agents/ai-memory.md`）

同一条结论只写一处。

## 决策树

1. **有未完成、下回要接着干的工作？** → 更新 `TASK_MEMORY.md`（目标 / 状态 / 阻塞或未决 / 涉及文件）
2. **能压成一句以后还用的坑位 / 约束 / 事实 / 平台？** → 按 `ai-memory.md` 格式写入 `AI_MEMORY.md`（≤2 句，无复盘）
3. **用户明确说「以后都按这个做」？** → 落盘到对应规范或 `AI_MEMORY.md`（同样短结论）
4. **命中已有观察项，或出现还不能写成规则的重复信号？** → 按 `.agents/continuous-learning.md` 计数；达阈值只通知用户
5. **收尾 / 压缩前** → 按 `ai-memory.md` 删除门槛扫存量（过期、实现细节、重复 → 删或合并）

### 明确不写（命中任一则跳过 AI_MEMORY）

- 拼写、文案、样式微调、单点空值/类型修补、依赖版本 bump
- 只影响当前文件、一眼能看出的修法
- 方案对比、推演过程、试错步骤、验证过程、会话复盘
- 函数级实现步骤、魔法数、调用次序（回代码 / PR）
- 「已修复」快照；或现行代码在决策点已能读出同一约束
- 整份 `AI_MEMORY.md` 已有同类内容（含架构地图 / 链路）

任务已完成：可复用结论只进 `AI_MEMORY.md`；**从 `TASK_MEMORY.md` 删掉该条目**（不留 `[已完成]` 摘要）。

全部为否 → 回复「无需落盘」。不写入操作流水和当前会话上下文。
